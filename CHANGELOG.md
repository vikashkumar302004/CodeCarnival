# Changelog

All notable changes to CodeCarnival are documented here.

## 1.1.1 — 2026-10-10

### Fixed

- Guaranteed comic artwork visibility above opaque LeetCode workspace layers using a pointer-safe blend layer
- Added current LeetCode Accepted tab detection so successful solutions trigger the celebration
- Replaced the city artwork with a sharper hand-inked graphic-novel environment

## 1.1.0 — 2026-10-10

### Fixed

- Rebuilt theme rendering around a real injected backdrop so LeetCode's opaque panels no longer hide the theme
- Made blur and shade controls affect the visible background correctly
- Added focused glass styling for the current LeetCode split workspace and Monaco editor

### Changed

- Replaced the six shallow presets with one deeply crafted Neon Web signature theme
- Added a cinematic bundled city background and a CSS-animated dancing web hero celebration
- Migrated existing preset selections automatically to Neon Web

## 1.0.0 — 2026-10-10

Production-ready release package.

### Added

- Original CodeCarnival extension icon and store artwork
- Chrome Web Store listing copy, permission justifications, and submission checklist
- Mandatory 1280×800 screenshot and 440×280 promotional tile
- Automated privacy, accessibility, performance, and compatibility quality gates

### Changed

- Promoted the extension manifest to version 1.0.0
- Added padded production icons at 16, 32, 48, and 128 pixels

## 0.5.0-beta — 2026-10-10

First public beta.

### Added

- Six visual worlds with theme-specific Accepted celebrations
- Custom image and GIF backgrounds
- Full-page Theme Studio with live preview
- Accent, blur, overlay, sound, intensity, and repeat controls
- Robust LeetCode SPA navigation and submission-result detection
- Connection diagnostics in the extension popup
- Versioned ZIP packaging and SHA-256 checksum generation

### Notes

- The beta is installed with Chrome's **Load unpacked** flow.
- Chrome Web Store distribution is planned for the production release.
