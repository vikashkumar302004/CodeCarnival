# Changelog

All notable changes to CodeCarnival are documented here.

## Summer Festival Rooftop theme — 2026-10-11

- Added an original riverside festival rooftop, visitor, and star-tail mascot
- Added all three promised Submit rockets with algorithm-tree, code-braces, and golden-border patterns plus rhythmic lanterns
- Added layered Accepted fireworks, character victory pose, mascot jump, moving reflections, and edge-only confetti

## Floating Sky Library theme — 2026-10-11

- Added an original cloud-top open library and sky librarian
- Added the complete promised Submit sequence: opening book, page turns, bookmark trail, and cloud reveal
- Added the complete Accepted finale: lantern illumination, glowing waterfalls, and flying golden paper birds

## Cyber Ronin and Lo-Fi Rain remaster — 2026-10-11

- Replaced both gradient-only worlds with original cinematic environment artwork
- Added an original armored Cyber Ronin, shrine depth, dual plasma slashes, and stronger speed-line choreography
- Added an original Lo-Fi coder, warm city loft, layered window rain, breathing motion, city glow, and rising mug steam

## Moonlit Last Train theme — 2026-10-11

- Added an original moonlit countryside station, traveler, and warm-window night train
- Added a Submit signal, approaching headlight, and firefly sequence
- Added a Next Stop: Success Accepted scene with a full cinematic train pass

## Sakura Sanctuary theme — 2026-10-11

- Added an original sunset cherry-blossom sanctuary and seated garden keeper
- Added a calm Submit breeze that stays away from question and editor content
- Added an Accepted scene with soft petals, lantern glow, and A Quiet Victory choreography

## Shadow Hacker theme — 2026-10-11

- Added the original Shadow Hacker, Bug Wraith, and Null District artwork
- Added Submit-triggered breach, teleport, triple-slash, glitch-pixel, and panel-fragment choreography
- Added a dedicated Bugs Eliminated Accepted finisher

## Volt Ranger theme — 2026-10-11

- Added the original Volt Ranger hero and Scrap Drone villain artwork
- Added a Submit-triggered battle with blaster shots, laser impacts, and controlled LeetCode panel drop-and-return choreography
- Added a cinematic rainy sci-fi city background, threat scanner, targeting reticles, muzzle flashes, impact debris, recoil, and synthesized blaster sound
- Added a dedicated Accepted victory scene and reduced-motion fallback

## React website — 2026-10-10

- Migrated the complete dashboard from static HTML/JavaScript to Vite, React, and strict TypeScript
- Split theme data, animation state, and visual sections into reusable components and hooks
- Replaced the static hero mockup with a looping LeetCode simulation: typing, submitting, Accepted, and cinematic celebration
- Added a verified production build and local Vite preview workflow
