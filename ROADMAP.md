# CodeCarnival production roadmap

CodeCarnival is planned as seven focused phases. Each phase ends with a validated commit on `main`.

| Phase | Scope | Status |
| --- | --- | --- |
| 1 | Foundation: website, Manifest V3 extension, theme engine | Complete |
| 2 | Theme-specific Accepted celebrations and packaging | Complete |
| 3 | Full Theme Studio, live preview, and preference controls | Complete |
| 4 | LeetCode compatibility hardening across layouts and navigation | Complete |
| 5 | Distribution website, versioned downloads, onboarding, and documentation | Next |
| 6 | Automated QA, performance, accessibility, and privacy review | Planned |
| 7 | Store assets, production build, Chrome Web Store submission readiness | Planned |

The first public beta can ship after Phase 5. Phase 7 is the production/store-ready milestone.
