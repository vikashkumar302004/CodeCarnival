# CodeCarnival privacy policy

CodeCarnival is designed to work without an account, analytics service, or backend.

## Data the extension uses

- The active CodeCarnival theme and visual preferences
- A custom background image, if the user chooses one
- Celebration behaviour such as sound and effect intensity

These preferences are stored locally with `chrome.storage.local`.

## Page access

CodeCarnival runs on LeetCode pages so it can:

- Apply the selected visual theme
- Detect the visible result of a submitted solution
- Display an Accepted celebration

The extension does not read or store solution source code, passwords, cookies, hidden test cases, browsing history, or personal LeetCode account information.

## Data sharing

CodeCarnival does not include analytics, advertising, remote scripts, or tracking pixels. It does not transmit user data to the project author or third parties.

## Removing stored data

Use **Reset** in the CodeCarnival popup or Theme Studio. Uninstalling the extension also removes its local extension storage according to Chrome's standard behaviour.

## Changes

Any privacy-impacting change will be documented in the changelog and reflected in this policy before release.
